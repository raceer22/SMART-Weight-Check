# U11 · Research 3 ways to weigh a compactor

**Time:** ~30 min  ·  **Do first:** U10

**Why:** Brief part 1 asks for an *affordable, retrofit-friendly* weighing idea. The dataset doesn't contain one, so it's our concept.

## Steps
1. Search the web for: load cells under the container, hydraulic pressure of the lift arm, strain gauges on the frame (or other ideas you find).
2. For each idea write: rough cost (cheap/medium/expensive), easy to retrofit? (yes/no), expected accuracy.
3. Put it in a 3-row table in FINDINGS.md.

## Done when
- [x] A comparison table of 3 ideas is in FINDINGS.md.
