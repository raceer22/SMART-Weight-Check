# S01 · Clone the repo and open it in VS Code

**Time:** \~10 min · **Do first:** -

**Why:** Everyone needs the same code and data on their laptop.

## Steps

1. Ask the team lead for the GitHub repo link.
2. In a terminal run `git clone <link>`.
3. Open VS Code → *File → Open Folder* → choose the `Since-AI` folder.
4. Check that you can see `README.md`, `data/` and `baselines/` in the sidebar.

## Done when

- [ ] The repo is open in VS Code on your laptop.
