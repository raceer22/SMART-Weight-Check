# C14 · Demo app: add evidence tags to every number

**Time:** ~20 min  ·  **Do first:** C11, C12

**Why:** The judging rubric gives full points only when every figure is tagged *observed / estimated / simulated / hypothetical*.

## Steps
1. Go through every number in the app.
2. Add a small label after it, e.g. `st.caption('observed – weighbridge ticket')`.
3. Add a footer: “All data is synthetic. Not Europress data.”
