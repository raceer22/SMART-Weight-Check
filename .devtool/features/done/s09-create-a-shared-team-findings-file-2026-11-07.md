# S09 · Create a shared team findings file

**Time:** \~5 min · **Do first:** -

**Why:** One place where everyone writes what they found. We'll copy from it for the pitch.

## Steps

1. Create `notes/FINDINGS.md`.
2. Add headings: `## Data`, `## Weight`, `## Customer value`, `## Business model`, `## Open questions`.
3. Commit and push it.

## Done when

- [ ] `notes/FINDINGS.md` exists on GitHub.

## Help

- Keep notes short: one finding = one bullet + where you saw it (table/script).
