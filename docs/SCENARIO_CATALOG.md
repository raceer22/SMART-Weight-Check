# Scenario catalog

38 scenario families. *Mechanism*: injected (parameters placed before simulation), emergent (arises from policy × demand × contract, labelled from truth), derived (observation / billing artefacts).
Coverage = counts in the generated **competition** profile (public + private): `borderline` / `clear` label counts where the family is labelled; `evidence` = count of rows exhibiting it where it is a data property.
